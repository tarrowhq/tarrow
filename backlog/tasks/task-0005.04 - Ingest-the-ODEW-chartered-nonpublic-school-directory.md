## Description

<!-- SECTION:DESCRIPTION:BEGIN -->
Ingest the Ohio Department of Education and Workforce chartered nonpublic school directory as an authoritative source for nonpublic school premises, replacing reliance on the federal Private School Universe Survey.

Raised by TASK-0002 P2, which found the gap by spot-checking rather than by any test failing. St. Vincent-St. Mary High School, 15 N Maple St, Akron, is absent from the PSS entirely, and its campus is held under a name no source identifies as a school (SVSM FOUNDATION PROPERTIES LLC), so the county tax-roll owner-name source added in the same phase did not recover it either.

The defect is structural, not a bug. PSS is a voluntary biennial survey, so a school that declines to respond simply does not exist to us. A source whose completeness depends on the goodwill of the subject is not an acceptable basis for a layer whose failure mode is under-restriction (Principle I). One confirmed miss is evidence of others.

Deliberately NOT fixed by widening the tax-roll owner-name heuristic. Tuning a pattern until it catches the one miss already known produces a source that looks complete and is not, which is worse than a declared gap.

ODEW publishes the directory only as spreadsheets, so this carries real extraction work and a human verification step per Principle V. Until it lands, the gap is declared by name in the coverage-gap ledger and rendered in the manifest.
